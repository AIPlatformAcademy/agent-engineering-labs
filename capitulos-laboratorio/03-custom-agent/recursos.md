# Recursos para profundizar

## Visual Studio Code

Documentación oficial sobre Custom Agents:

[Custom agents in VS Code](https://code.visualstudio.com/docs/agent-customization/custom-agents)

Explica cómo crear, configurar, seleccionar y utilizar Custom Agents en VS Code.

---

## GitHub Copilot

Referencia oficial para configurar Custom Agents:

[Custom agents configuration](https://docs.github.com/en/copilot/reference/custom-agents-configuration)

Incluye las propiedades disponibles para los perfiles de agentes, como:

```text
name
description
target
tools
model
```

---

## GitHub Copilot CLI

GitHub también documenta la creación de especialistas mediante archivos `.agent.md` y el uso de `.github/agents/` para agentes almacenados en el repositorio:

[Creating and using custom agents for GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/create-custom-agents-for-cli)
